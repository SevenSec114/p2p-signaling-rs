# p2p-singaling-rs
This repo is mainly use for establishing p2p connection, acting as a signaling server.

## Usage
Run the server with `cargo run`, it will start a WebSocket server listening on port in `config.yaml`.

## Docs
There are 3 types of messages:
1. register
  ```ts
  { "register": "id" }                 // id is generated by the client code and should be unique
  { "register": "id", "force": true } // kick any existing connection holding the same id (like `git push -f`)
  ```
  If the id is already taken and `force` is not set, the server replies with an error
  ("id `<id>` taken") and does NOT modify the existing registration.
2. query (inspect whether an id is currently registered, without changing anything)
  ```ts
  { "query": "id" }
  // reply:
  { "id": "id", "registered": true | false }
  ```
3. forward
  ```ts
  /* idA is the sender, idB is the receiver
     the rest message could be anything like ice, SDP answer
     and so on, will be directly forwarded to the other peer
  */
  {
    "from": "idA",
    "to": "idB",
    ...
  }
  ```

## Notes
This repo does not provide STUN/TURN server. You can use [coturn](https://github.com/coturn/coturn) for this purpose.
